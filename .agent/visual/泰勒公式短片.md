## 观察结果

- 开场：第 0 帧有三倍大的橙点、冲击环和从点向两边画出的曲线；n = 1、2、3、5、8、12、18、26、40 逐拍出现，n = 40 时橙色盖满整条曲线；分屏标题“泰勒公式”跨过曲线，上墨下白；“凭什么？”与“从一条切线说起”清楚。
- 切线：×1 → ×1,000 放大，曲线与切线重合；急退后橙色误差段出现；公式与 o(x − x₀) 依次出现，读数在急退后消失。
- 系数：x³ → 3x² → 3·2x¹ → 3·2·1 → 3!；多项式中低次项和 a₄x⁴ 落下，剩 p‴(0) = 3!·a₃，重排成 a₃ = p‴(0)/3!，再到 aₖ = f⁽ᵏ⁾(x₀)/k!。f 与上标 (k) 不再相撞。
- 泰勒多项式：T₀ 到 T₆ 逐阶弯曲，右侧导数塔逐层亮起；求和公式完整。
- 佩亚诺：显微镜下 (x − x₀)² 形状不变，R₂ 从可见到压平（h = 3.00 → 0.004）；洛必达各层逐层穿过，最后 “= 0”；公式与名称。
- 麦克劳林：转轮停在六个展开上，函数名与自变量之间有空隙；结尾六个函数名在两道线之间。
- 求极限：两行展开对齐，相同项相撞炸成粒子，剩下的项由粒子聚成 −x⁴/12，结论 −1/12。
- 拉格朗日型余项：x₀ 翻成 ξ，数轴上 ξ 落在 x₀ 与 x 之间；n = 0 三步翻折后移项成 f(x) − f(x₀) = f′(ξ)(x − x₀)，橙色下划线。
- 算 e：方块逐拍落下，滚轮读数 1.000000 → 2.718282，放大镜看到塔顶越来越薄的层，误差界与 “e ≈” 出现，放大镜不再压住读数。
- 误差范围：|x| < 0.1817、0.6543、1.2599、1.9249、2.6199 逐级展开，镜头拉远，旧括号留在下面。
- 收尾：碎片第 0 帧就散在画面里并逐个归位；三处标注；分屏两行结论；最后回到橙点，墨圈只在点周围收住，不压字。
- 切点：11 条连续帧里，切点帧都是新构图的第一帧，前一帧是上一场景，切换干净。
- 波形：开场前 16 拍 bgm 压低，标题处起来；第 144—176 拍间奏较低，第 176 拍第二段进来；切点和重音处有尖峰，没有削顶的平顶；结尾两秒和弦衰减后淡出。
