# 嘉宾 MV 成片的抽帧检查

2026-11-03，用户要求用 ffmpeg 抽帧核对歌词。制作期间另外逐镜查看了样张。

- 改动文件：`嘉宾/MV/kit.js`、`sets.js`、`poses.js`、`covers.js`、`film.js`、`main.js`、`lyrics.js`
- 页面：`嘉宾/MV/index.html`，由 `render-film.mjs` 逐帧输出
- 视口：1920×1080；抽帧总览每格 480×270
- 图片：`嘉宾/MV/輸出/抽帧/每句起点.jpg`（46 句各自出现的第一帧）、`嘉宾/MV/輸出/抽帧/全片取样.jpg`（全片等距 48 帧）。两张都在已忽略的 `輸出/` 下，由 `verify-export.mjs` 重新生成。

## 观察结果

- 46 句的第一帧都显示本句歌词，位置固定在画面下方，不随相机变化。
- 歌词在切点后约半拍内出现时，第一帧正好落在遮挡物盖满的时刻（L06、L07、L09、L10、L13、L16、L18、L21、L25、L26、L30 等），画面是一片红、金、纸片或门板。这是切点规则的结果：切点在起唱前 0.074–0.727 秒。
- 全片取样能看到分镜的主要段落：雪路、霜窗、祝福气泡、婚礼布置、握手、拉钩、最后一排、戒指、红线、纸舞台、窗外、合影、同一条路和雪盖席卡。

## 制作中发现并修复

- 遮挡物跟着上一镜的相机走，走廊里的白头纱位置全错。遮挡物改为画面座标。
- O01 结尾主角没有走出画面，O02 第一帧突然消失。
- L17、L23 的席卡文字和歌词重叠。歌词改为贴在奶油色纸条上。
- L19、L20 的舞台右侧露底纸。舞台向右加长。
- L20 戒指比已确认的定格小三倍。按特写时的画面尺寸重算。
