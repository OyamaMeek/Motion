# 《如何在算法时代保持清醒》短片工程

依据 [算法时代的清醒.md](../算法时代的清醒.md) 制作，主题“把选择权拿回来”。成片 `输出/如何在算法时代保持清醒.mp4`：1920×1080、30 fps、30 秒，配乐由代码合成并混入。MP4 只留本地，不提交。

- `timeline.js`：120 BPM，每拍 15 帧；封面 6 拍、五个年份节点各 9 拍、结尾 9 拍。翻页 12 帧，拍点那一帧新页完全露出。
- `script.js`：画面上的全部文字，每句标注来源编号；逐句原文见 [来源对照.md](来源对照.md)。换行位置写在文字里的 `\n`，绘制时出现自动断行会记为渲染错误。
- `main.js`：Canvas 2D 绘制。暖白纸底、黑字、朱红 `#c8361d` 一个强调色，年份用 Didot，中文用宋体。旧页绕左缘朝观众翻起，按竖条透视投影；底部时间尺常驻，标记随翻页移到对应日期。
- `music.mjs`：D 大调 I–vi–IV–V，拨弦琶音、底鼓、低音、铺底和翻页声，翻页落定的拍点有纸页落下的重音，结尾每打一个勾响一声。
- `render.mjs`：复用 `會呼吸的痛/開場樣圖/v2/chrome.mjs` 驱动 3 个无头 Chrome 分段渲染，ffmpeg 编码，AAC 混入配乐。
- `verify-export.mjs`：检查规格、每次翻页最后一帧运动是否正好在拍点、解码后音轨重音偏差、响度和真峰值，结果写入 `输出/导出检查.json`。

```bash
node --test 算法时代的清醒/短片/film.test.mjs
```

```bash
node 算法时代的清醒/短片/render.mjs
```

```bash
node 算法时代的清醒/短片/verify-export.mjs
```

```bash

```
