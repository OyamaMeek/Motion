# 《八个字，一生的回答》短片工程

依据 [选题方案](../八个字，一生的回答-选题方案.md) 制作。成片 `输出/八个字，一生的回答.mp4`：1920×1080、30 fps、90 秒、2700 帧，H.264 视频、AAC 音频，配乐由代码合成。MP4、WAV 只留本地，不提交。

- [脚本与时间表.md](脚本与时间表.md)：逐页文字、打字拍点、落拍帧、配乐段落。
- [来源对照.md](来源对照.md)：每句事实性文字的来源、发布机构、链接和原文；查到但没有采用的说法。
- `timeline.js`：120 BPM，每拍 15 帧，13 页共 180 拍；每页在 `land` 帧完成翻页的关键动作（新场景或大字硬切进入）。
- `script.js`：画面上的全部文字，每句标注类型（史实、引语、作者理解、标注）和来源编号。
- `main.js`：Canvas 2D 绘制。第 1—11 页墨黑暗场（顶部聚光、暗角、浮尘、胶片颗粒），最后两页米白纸面；朱橙 `#FD602A` 只落在一个词、一组方块或一组点上，批注用红色手绘圈；粗宋 Songti SC Black、宋体、Menlo、DIN Condensed。开场逐半拍满屏重击的八个字、冲击环、透视文字平原、橙色方块、字形内的电子管纹理与穿过“0”的推进、雾层、无脸剪影、电子管线图、里程表年份、名册扫描条、特写拉远、两地弧线与沿弧线飞行的球、试卷、光轮、字墙与细线框、走线电流、仰望的人群剪影、文字崩塌都由代码绘制；墨点和无人机点阵由字形均匀取点生成；示意图形旁标注“图形示意”。
- `music.mjs`：A 小调 Am–F–C–G，铺底、钢琴、拨弦、低音、底鼓、踩镲按页面配器；每个落拍帧有底鼓、纸声和钟声。
- `render.mjs`：复用 `會呼吸的痛/開場樣圖/v2/chrome.mjs` 驱动多个无头 Chrome 分段渲染，ffmpeg 编码，混入 AAC 配乐；任何一帧 60 秒未返回即报错终止。渲染约 7—9 分钟，期间电脑不能睡眠或合盖。
- `verify-export.mjs`：检查规格、音画起点、每个落拍帧的画面变化是否为前后 3 帧最大、音轨重音偏差与强度、响度、真峰值、削波、爆音和中断，结果写入 `输出/导出检查.json`。
