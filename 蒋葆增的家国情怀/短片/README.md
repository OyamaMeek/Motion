# 《八个字，一生的回答》短片工程

依据 [选题方案](../八个字，一生的回答-选题方案.md) 制作。成片 `输出/八个字，一生的回答.mp4`：1920×1080、30 fps、90 秒、2700 帧，H.264 视频、AAC 音频，配乐由代码合成。MP4、WAV 只留本地，不提交。

- [脚本与时间表.md](脚本与时间表.md)：逐页文字、打字拍点、落拍帧、配乐段落。
- [来源对照.md](来源对照.md)：每句事实性文字的来源、发布机构、链接和原文；查到但没有采用的说法。
- `timeline.js`：120 BPM，每拍 15 帧，13 页共 180 拍；上一页的元素在最后一两拍交给下一页，每页在 `land` 帧发生一个明确动作（大字落下、场景点亮或物件定格）。
- `script.js`：画面上的全部文字，每句标注类型（史实、引语、作者理解、标注）和来源编号；`floor` 是文字平原与第 9 页地面上的小字（三条释义加史实关键词）。
- `main.js`：Canvas 2D 绘制，自写透视相机（位置、俯仰、偏航、焦距）：贴图平面逐屏幕行反算贴图行，点、线和方块角点直接投影。第 1—11 页墨黑暗场（顶部聚光、暗角、浮尘、胶片颗粒），最后两页米白纸面；朱橙 `#FD602A` 只落在一个词、一组方块或一组点上，批注用红色手绘圈；粗宋 Songti SC Black、宋体、Menlo、DIN Condensed。开场墨滴落地、墨迹沿电路走线流开的晶格平原与实验手稿线条、地面上显影再立起的八个字、立体方块落在文字平原上、冲进“大”字方块的推进、转动的电子管立体线框、穿过“0”的推进、翻下的名册、里程表年份、后退的地面网格、绕转的立体地图与弧线、空中翻正的试卷、物件拼成“大”的俯瞰平原、向后倒下的电路板、电路纹理地面与升空点阵、文字崩塌都由代码绘制；墨点和无人机点阵由字形均匀取点生成；示意图形旁标注“图形示意”。
- `music.mjs`：A 小调 Am–F–C–G，铺底、钢琴、拨弦、低音、底鼓、踩镲按页面配器；开场有墨滴落地、八个字逐个显影、立定与炸开的击打；每个落拍帧有底鼓、纸声和钟声。
- `render.mjs`：复用 `會呼吸的痛/開場樣圖/v2/chrome.mjs` 驱动多个无头 Chrome 分段渲染，ffmpeg 编码，混入 AAC 配乐；任何一帧 60 秒未返回即报错终止。渲染约 7—9 分钟，期间电脑不能睡眠或合盖。
- `verify-export.mjs`：检查规格、音画起点、每个落拍帧的画面变化是否为前后 3 帧最大、音轨重音偏差与强度、响度、真峰值、削波、爆音和中断，结果写入 `输出/导出检查.json`。
