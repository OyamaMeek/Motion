# 《八个字，一生的回答》短片工程

依据 [选题方案](../八个字，一生的回答-选题方案.md) 制作。成片 `输出/八个字，一生的回答.mp4`：1920×1080、30 fps、90 秒、2700 帧，H.264 视频、AAC 音频，配乐由代码合成。MP4、WAV 只留本地，不提交。

- [脚本与时间表.md](脚本与时间表.md)：逐页文字、打字拍点、落拍帧、配乐段落。
- [来源对照.md](来源对照.md)：每句事实性文字的来源、发布机构、链接和原文；查到但没有采用的说法。
- `timeline.js`：120 BPM，每拍 15 帧，13 页共 180 拍；每页在 `land` 帧翻转底色。
- `script.js`：画面上的全部文字，每句标注类型（史实、引语、作者理解、标注）和来源编号。
- `main.js`：Canvas 2D 绘制。米白纸面、暖米纸、墨黑暗场按拍交替，朱橙 `#FD602A` 每画面只落在一个词或一组点上；粗宋 Songti SC Black、宋体、Menlo、DIN Condensed。墨点、无人机点阵由字形均匀取点生成。电子管、清单、电路、点阵都标注“图形示意”。
- `music.mjs`：A 小调 Am–F–C–G，铺底、钢琴、拨弦、低音、底鼓、踩镲按页面配器；每个落拍帧有底鼓、纸声和钟声。
- `render.mjs`：复用 `會呼吸的痛/開場樣圖/v2/chrome.mjs` 驱动多个无头 Chrome 分段渲染，ffmpeg 编码，混入 AAC 配乐。
- `verify-export.mjs`：检查规格、音画起点、每个落拍帧的画面变化是否为前后 3 帧最大、音轨重音偏差与强度、响度、真峰值和削波，结果写入 `输出/导出检查.json`。


```bash

```

