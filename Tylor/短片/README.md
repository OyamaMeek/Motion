# 《泰勒公式》短片工程

把 `Tylor/泰勒公式.md`（华东师大《数学分析》第六章第三节）里的泰勒公式整条逻辑链做成一部 152 秒的讲解短片：1920×1080、30 fps、4560 帧，H.264 视频、AAC 音频。画面、曲线、公式全部由代码绘制，不用图片素材；配乐由仓库根目录的 `bgm.mp3` 和代码合成的一层混成。成片 `输出/泰勒公式.mp4` 与 WAV 只留本地，`bgm.mp3` 不提交。

## 设计

- 核心意象是“一个点”：橙色的 x₀ 贯穿全片。第 0 帧橙点砸下、冲击环扩开、曲线从点向两边画出；逐拍取更高阶，多项式从这个点长出整条曲线（n = 1 → 40）；标题用曲线把画面分成上米白、下亮橙，“泰勒公式”跨过分界线，上半墨黑、下半米白。收尾回到这个分屏和这个点。
- 配色：米白 `#F2EDE4` 底、墨黑 `#161412`、亮橙 `#FF5B14`。标题字体 PingFang SC（中文字幕与标题），正文字体 STIX Two Text（公式与数字，变量斜体）。
- 十一段，每段只讲一件事，每段一种动效手法；切点都在 120 BPM 的小节首拍：

| 拍 | 场景 | 内容 | 手法 |
| --- | --- | --- | --- |
| 0—32 | 开场 | 一个点的导数长出整条曲线；凭什么？ | 曲线生长、分屏标题、逐字砸下 |
| 32—56 | 切线 | 放大到 1000 倍曲线就是直线；一阶近似与 o(x − x₀) | 十进位连续放大、急退 |
| 56—84 | 系数 | x³ 求三次导，指数逐个落下成 3!；aₖ = f⁽ᵏ⁾(x₀)/k! | 大字拆开重组、按标签重排 |
| 84—116 | 泰勒多项式 | 同值、同斜率、同弯曲……直到 n 阶 | 弹性形变、两座导数塔逐层亮起 |
| 116—144 | 佩亚诺型余项 | 误差比 (x − x₀)ⁿ 消失得快；洛必达用 n − 1 次 | 横按 h、纵按 h² 缩放的显微镜；镜头穿越深度平面 |
| 144—176 | 麦克劳林公式 | x₀ = 0 的六个常用展开 | 老虎机转轮急停 |
| 176—204 | 求极限（例 4） | 代入展开，同项抵消，剩 −x⁴/12，极限 −1/12 | 粒子相撞炸开、粒子聚成新项 |
| 204—236 | 拉格朗日型余项 | 下一项的导数取在 ξ；n = 0 即拉格朗日中值定理 | 翻牌、逐步翻折 |
| 236—260 | 算 e（例 6） | 加到 1/9!，e ≈ 2.718282，误差 < 3/10! < 10⁻⁶ | 方块下落堆叠、数字滚轮、放大镜 |
| 260—280 | 误差范围（例 7） | 误差 < 10⁻³ 的范围 0.1817、0.6543……次数越高管得越远 | 区间括号伸展、镜头拉远 |
| 280—304 | 收尾 | 公式各部分归位并标出来源；“导数，造出多项式 / 余项，管住误差” | 碎片归位、分屏 |

- 数值以计算为准：Σ1/k!（k ≤ 9）= 2.7182815，显示 2.718282（教材印的 2.718285 超出它自己给的 10⁻⁶ 误差界）；教材拉格朗日型余项一行的排版错误按 `(x − x₀)ⁿ⁺¹`、`ξ = x₀ + θ(x − x₀)` 处理。

## 文件

- `timeline.js`：120 BPM、每拍 15 帧、304 拍，场景长度、切点、场景内关键拍 `KEYS`、重音 `HIT_BEATS`。
- `script.js`：全部中文字幕，每条不超过 14 字；`^{}` 上标、`_{}` 下标、`[…]` 亮橙。
- `math.js`：泰勒多项式（由各阶导数造系数）、讲解曲线 f(x) = sin x + 0.35 sin 2x、sin x 的展开、例 4 / 例 6 / 例 7 的数值、eˣ 的拉格朗日型余项反解 ξ。画面与测试共用。
- `reel.js`：麦克劳林转轮的位置函数，画面与棘轮声共用。
- `tex.js`：公式排版（TeX 子集：`\frac`、上下标、`\sum`/`\lim` 上下限、`\o{}` 亮橙、`\t{标签}{}` 标签组），排成逐字形列表。
- `draw.js`：逐字形绘制、安全区检查（墨迹超出左右 60、上下 40 像素即报错；砸下时的放大自动压到放得下的倍数）、字幕逐字落下、按标签重排、粒子取样、函数图像相机。
- `film.js`：十一个场景。
- `audio.mjs`：bgm 用 ffmpeg `atempo` 变速不变调到 120 BPM，第一小节首拍对上成片第 0 拍，整首不剪（前奏垫开场，间奏垫麦克劳林，第二段在求极限进来）；合成层是“精密仪器”音色——十六分音符滴答、FM 玻璃钟（开场逐阶沿 F 小调音阶上行）、次低音下沉、反向噪声涌起、木块、翻牌声、棘轮；bgm 经旁链在重音处压低；母带软限幅。
- `analyze-bgm.py`：测 bgm（112.90 BPM、F 小调、小节首拍相位、每小节能量与和弦），写 `bgm.json`。
- `browser.mjs`：经 `--remote-debugging-pipe` 驱动无头 Chrome。`render.mjs`：多进程分段渲染、编码、混音。
- `check.mjs`：成片检查与抽帧；`bgm-grid.py`：拉伸后的 bgm 是否在成片拍格上。
- `film.test.mjs`：时间轴、字幕、数学数值、转轮、bgm 计划、配乐电平。
