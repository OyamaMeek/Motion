# 《會呼吸的痛》开场画风样图 v2

三张均为 **1920×1080 PNG**，由代码绘制，未使用图像生成模型。

共同画面取自 L01–L04：黄昏的东京铁塔，Clawd 独自坐在露台长椅的一端，隔着空位和两张车票望向铁塔，行李箱停在脚边。几粒金色光点从高空坠向城市，呼应 L02「看燈火模仿 墜落的星光」。全图为浅色黄昏，天空只用灰蓝到杏色，不含文字。

| 样图 | 绘制方式 | 适配理由 |
| --- | --- | --- |
| [01-像素遊戲.png](01-像素遊戲.png) | Canvas 2D 在 320×180 上逐格绘制，全图 31 色，渐变用 Bayer 点阵，关闭平滑后放大 6 倍 | 有限的颜色像一段存进旧卡带的记忆，小小的角色与高塔并置，「一個人完成 我們的夢想」的落差一眼可见。 |
| [02-紙藝拼貼.png](02-紙藝拼貼.png) | Canvas 2D 分层纸片：牛皮纸底、旧报纸远景、撕纸毛边、剪纸白边和投影 | 歌里疼痛来自信件这类旧物，撕开又叠起的纸片把想念变成一本贴满票根的手账。 |
| [03-蠟筆手繪.png](03-蠟筆手繪.png) | p5.js 2.2.0 + p5.brush 3.0.0：以内置 crayon 参数定义 `wax` 笔刷，逐笔排线，留白露纸，再压纸张颗粒 | 笔触抖动、处处露出纸白，像忍住没说完的话，最贴近主歌一的克制与空落。 |

## 动画规则

| 画风 | 规则 |
| --- | --- |
| 像素 | 全片沿用同一调色板；角色逐帧换画，不做补间 |
| 纸艺 | 每秒更新 8–12 次，每次各层随机抖动 1–2 像素 |
| 蜡笔 | 选定后另行确定 |

当前只有静态样图，以上动画规则尚未实现和验证。

## 角色

像素版调用 [assets/clawd/character.js](../../../assets/clawd/character.js)。纸艺和蜡笔版按同样的 32 格比例重画，几何数据在 `scene.js` 的 `CLAWD_PARTS`。用户已确认全片主角使用 Clawd。

## 重现

依赖保存在 Git 忽略的 `.agent/work/art-libs/`，下载方法见[上一版说明](../README.md#重现)。渲染脚本使用本机 Chrome 无头模式，运行时会重写三张 PNG 和 `驗證結果.json`：

```bash
node 會呼吸的痛/開場樣圖/v2/render.mjs
```

脚本检查尺寸、不透明度和浏览器错误；像素版另外检查原生尺寸、16–32 色范围和全部 6×6 色块一致。结果见 [驗證結果.json](驗證結果.json)。
