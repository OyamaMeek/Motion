# 《會呼吸的痛》图像分镜

依据 [會呼吸的痛storyboard.md](../會呼吸的痛storyboard.md) 的 41 个镜头，每镜一张 1920×1080 关键画面，用代码绘制，未使用图像生成模型。总览见 [分鏡/storyboard.png](分鏡/storyboard.png)，每格下方标注镜号、起止时间、关键帧时刻和歌词；单镜画面是 `分鏡/P01.png` 到 `分鏡/L37.png`。

成片为像素画风，1920×1080、12 fps，完整覆盖 04:33.043，输出到本地的 `輸出/會呼吸的痛_MV.mp4`（不进入 Git）。`分鏡/` 中的 41 张图是用户确认的草图，成片沿用其构图和时间，并补上材质、光影与动画。

## 结构

| 文件 | 内容 |
| --- | --- |
| `shots.js` | 41 镜起止时间与帧率 |
| `film.js` | 把任意时刻换算成绘制清单：场景、相机、角色和物件 |
| `geometry.js` | 从 `assets/clawd/character.js` 取得 Clawd 的几何 |
| `pixel.js` | 把绘制清单画到 320×180，放大 6 倍；最后在同一画布上画固定的歌词层 |
| `lyrics.js` | 读取 LRC，换算每句的出现与消失帧 |
| `vocal_measure.py` | 从原曲测量人声音高的起止（`人聲測量.json`）和每帧响度（`energy.js`） |
| `render-film.mjs` | 用本机 Chrome 逐帧绘制，经 ffmpeg 输出 MP4；音轨直接复制原曲 |
| `verify-export.mjs` | 对 MP4 抽帧核对歌词，测量响度并比对解码后的音频 |
| `render.mjs` | 输出草图风格的关键画面和总览；成片美术已写入 `film.js`，重新运行会覆盖确认稿，不再用于成片 |

背景、角色和道具在同一张清单里，由同一相机绘制；窗外城市和前景路灯按各自的纵深比例跟随相机，形成视差。歌词最后绘制，不经过相机，位置固定在画面下方。Clawd 的手只用 `character.js` 自带的长度，不另画手臂；测试会拦下任何额外的手臂，也逐处比对衔接前后的相机与角色方框。

```bash
node --test 會呼吸的痛/MV/shots.test.mjs 會呼吸的痛/MV/film.test.mjs 會呼吸的痛/MV/lyrics.test.mjs 會呼吸的痛/MV/art.test.mjs
```

```bash
node 會呼吸的痛/MV/render-film.mjs
```

```bash
node 會呼吸的痛/MV/verify-export.mjs
```

## 成片在草图之上补充的内容

分镜的动作、时间和构图不变，下列内容都放在场景内，不增加剧情。

| 内容 | 做法 |
| --- | --- |
| 呼吸 | 角色躯干随半速约 56 BPM 持续起伏，副歌里更深；另有眨眼 |
| 灯火 | 窗外灯火的数量跟随原曲响度；L02 有一道灯火带由上向下落；尾奏逐渐熄灭，最后只剩电梯的光 |
| 夜色 | 窗外由 L01 到间奏前逐渐转暗，地上的窗光同步减弱 |
| 倒影与雾气 | A 背对观众望向窗外时，玻璃上有 A 的倒影和呼吸的雾气 |
| 等待 | L18 饭菜的热气散尽，屋里变暗；L19、L20 玄关挂钟与回信草图同为 19:00 |
| 离开 | 开门后暖光洒到门外的夜色里 |
| 空电梯 | 楼层灯先走到本层，门开后露出亮着的空轿厢，灯光洒到空椅旁的地面 |
| 换景 | 门柱、信封、日历、围巾、计划、手机机身各有材质，前缘带阴影 |
| 手机画面 | L31、L32 的笑容不变，背景换成桌面与虚化的灯 |

## 与文字分镜的差异

Clawd 的手很短，文字分镜里需要伸手的动作都改成了下面的做法。

| 镜头 | 文字分镜 | 当前画面 |
| --- | --- | --- |
| P02 | A 一开始已在桌前，把信摊开 | A 从电梯旁走到座位，车票先在手尖，到座后纸才由手边展开 |
| L29、L33、L34 | A 坐着，手沿手臂入画，在信纸上写字和补画 | A 跳上桌子，站在信纸上写，笔拿在手尖 |
| L27、L28、L30 | A 坐着把手伸到空椅、拿起圍巾 | A 起身走到空椅旁再回座；L30 走过去后站着抱圍巾，到 L33 前回到桌上 |
| L14、L28、L19、L20 | 把手伸向空椅或 A | 用设计稿里的双手前伸姿势，手很短，离对方还很远 |
| L04、I01、L37 | 手移动车票、展开计划 | A 贴近桌边，车票在手尖旁移动；计划的折角改到左下角 |
| L05 | B 坐着挪日历贴纸 | B 站到椅子上；日历挂得更低 |
| L06、L13、I02 | B 把钥匙、圍巾、计划推过桌面 | B 贴近桌边；钥匙被推后自己滑过去，圍巾从手尖向外伸，计划被拉到 B 面前 |
| L12、L26 | 拇指摩挲手腕 | 手尖上的小圆点来回移动，只能大致看出 |
| L07、L24 | 手抵胸口、手掩嘴 | 手够不到身体中央：L07 只靠吸气位移，L24 用双手前伸姿势代替 |
| L16 | 桌沿遮住上身，只见桌下双手 | 桌沿遮住头部，手是两侧手尖上的圆点 |
| L22、L35 | 蜷缩、护胸 | 方块身体无法弯曲，只有下沉和双手前伸 |
| A 与 B | 以固定配色及 B 的圍巾区分 | 两人配色相同，只靠圍巾和座位区分 |
| L31、L32 | 手机取景 | 手机画面使用单独绘制的场景 |
| L29 | 书写「其实我很想你」 | 文字由系统字体生成，再转成像素 |
