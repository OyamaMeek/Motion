# 《會呼吸的痛》图像分镜

依据 [會呼吸的痛storyboard.md](../會呼吸的痛storyboard.md) 的 41 个镜头，每镜一张 1920×1080 关键画面，用代码绘制，未使用图像生成模型。总览见 [分鏡/分鏡總覽.png](分鏡/分鏡總覽.png)，左上角标注镜号和起始时间；单镜画面是 `分鏡/P01.png` 到 `分鏡/L37.png`。

分镜统一用像素画风绘制，确认后再用于其他画风。目前没有制作动画，也没有渲染视频。

## 结构

| 文件 | 内容 |
| --- | --- |
| `shots.js` | 41 镜起止时间 |
| `film.js` | 把任意时刻换算成绘制清单：场景、相机、角色和物件 |
| `geometry.js` | 从 `assets/clawd/character.js` 取得 Clawd 的几何 |
| `pixel.js` | 把绘制清单画到 320×180，放大 6 倍输出 |
| `render.mjs` | 用本机 Chrome 输出关键画面和总览 |

观景层是一个连续场景，桌面特写只是相机推近，物件不会按镜头增减。

```bash
node --test 會呼吸的痛/MV/shots.test.mjs 會呼吸的痛/MV/film.test.mjs
```

```bash
node 會呼吸的痛/MV/render.mjs
```

## 与文字分镜的差异

这些地方需要在确认分镜时一并决定：

| 镜头 | 文字分镜 | 当前画面 |
| --- | --- | --- |
| 全部人物动作 | 垂头、哼唱、咬唇、蜷缩、掩嘴等细微动作 | Clawd 是方块身体，只能靠表情、位移和手臂表达。L22 的蜷缩、L35 的护胸最不明显 |
| A 与 B | 以固定配色及 B 的围巾区分 | 两人配色相同，只靠围巾和座位区分 |
| 换景 | 只遮住需要更换的区域，约一拍 | 实物色块横扫并盖满全屏 |
| L12、L26 | 手腕特写 | 相机推近后，手腕是一小段手臂，拇指是圆点 |
| L16 | 桌沿遮住上身，只见桌下双手 | 桌沿只遮住上半部，仍能看见 B 的眼睛以下 |
| L27、L28、L30 | A 坐着把手伸到空椅、拿起圍巾 | 手臂只有身体那么长，够不到，所以 A 起身走到空椅旁再回座；L30 走过去后站着抱圍巾 |
| L14 | 手伸向空椅，停在空处 | 手只伸到桌面上方，离空椅还很远 |
| L05 | B 坐着挪日历贴纸 | B 站到椅子上挪贴纸，日历挂得更低 |
| L06、L13、I02 | B 把钥匙、圍巾、计划推过桌面 | B 凑到桌前；钥匙被推后自己滑过去，圍巾由手拿着向外伸，计划被拉到 B 面前 |
| L29、L33、L34 | A 的手沿手臂连续入画 | 桌面特写看不到 A，手从画面下缘伸入 |
| L31、L32 | 手机取景 | 手机画面使用单独绘制的场景 |
| L29 | 书写「其实我很想你」 | 文字由系统字体生成，再转成像素 |
