# 《苏轼》参考视频视觉风格

- 参考文件：`苏轼/苏轼.MOV`，1280×720，30 fps，2495 帧，83.17 秒，AAC 44.1 kHz 立体声。文件元数据写有“抖音作者：风摇叶见蝶”。
- 方法：每 0.5 秒一帧共 166 张，逐张查看（观察表 `.agent/visual/苏轼风格.md`）；快速段落另按 10 fps 或 30 fps 补看。librosa 0.11.0 测节拍；全片逐帧计算画面差和颜色直方图变化，判定切点；K-means 统计配色。数据在 `测量.json`、`节拍点.csv`、`切点.csv`，由 `分析视频.py` 生成。
- 未执行：播放器连续观看、人耳听辨。没有确认音轨里是否有人声旁白。字体名称靠字形推断，没有读取工程文件。

## 1. 风格概括

米白纸面与全黑暗场按拍交替，用 3D 文字、墨点粒子和浓雾里的极小人物把一个人的经历写成“由字构成的世界”，整片几乎无彩，只把一种朱橙色留给命运转折处的关键字。

## 2. 配色方案

饱和像素（饱和度大于 0.45）只占全片像素的 4.1%。逐秒平均饱和度在纸面和灰阶段落为 0.04–0.07，只在关键字出现的几秒升到 0.4–0.69。

### 用色规律

- 一个画面只有一种强调色，并且只落在一个字或一组字上；其余元素保持黑、白、灰和米色。
- 暗场里唯一保留颜色的物体就是叙事主角，例如两次关灯后只剩“盛”是橙色（9.7、55.2 秒）。
- 补色只作为单帧冲击，不在画面中停留。
- 明暗按段落交替：亮 0–9.6 秒，暗 9.6–22 秒，雾亮 22–24 秒，暗 24 秒，亮 26–35 秒，暖 35–38 秒，暗 38–46 秒，亮 46–55 秒，暗 55–65 秒，亮 65–83 秒。每段 5–12 秒，每次翻转都在拍点或半拍上。
- 暗场带顶部聚光或中央微亮的暗角；纸面中心略亮、四周略暗，纸面有极淡的纹理。

## 3. 角色与背景的绘制手法

### 角色

- 人物是无脸剪影：斗笠、长袍、竹杖，深灰单色 3D 模型，不画五官，不做特写。
- 人物在画面中的高度（目测）：竹林段约 1/6 到 1/9，海面段约 1/24。处境靠人物与环境的尺度对比表现，人物越孤立，画面越大越空。
- 人物放在下半部的左右三分线附近，动作只有缓慢行走或站立；脚下有一圈细环（21.2 秒为红色）标出位置。
- 很多段落没有人物，由文字本身承担角色：一个字被挑出来，经历升起、碎裂、坠落，例如“盛”从 6.7 秒到 55.7 秒跨越三个段落。

### 背景

- 纸面：米白或暖米底，几乎空白，只放文字、墨点或少量物件。
- 灰阶 3D 环境：竹林、江面、海面、月夜云层，全部去色。层次靠体积雾：近景竹竿接近黑色，远景溶进雾里，类似水墨的浓淡分层。雨是白色短线，夹少量带运动模糊的粗雨滴；云用水墨质感的灰白絮状纹理。
- 文字构成的环境：成片的小号诗文铺成地面、墙面或书页网格，中间留一条白路通向灭点（6.7–9 秒）。
- 墨点粒子与点描：山、墨团、诗句都可以由墨点堆积生成，也可以散回墨点。山用点云堆出山脊和山尖（32–35 秒）。
- 3D 字物：橙色立方体上的白字，带短软投影；挤出成立体的单字或词（“怕”“谁怕？”“大”）；带噪点纹理的球体（荔枝）；黑色字卡上发光的橙字，翻面后是白卡竖排诗句加橙色小方印。
- 字形当容器：巨大年份数字内部填书法或山水纹理（24.8–26.2 秒），“〇”直接作为进入下一场景的门洞。
- 批注符号：手绘红圈圈住关键字（10–11 秒、62 秒）；细线框住一句话（58–61 秒）。
- 光：整体柔光，没有硬阴影；暗场用顶部聚光；月亮和雾可以推到过曝白，作为段落出口。

## 4. 画面切换频率与镜头内运镜

### 节拍

- librosa 测得 152 BPM，平均拍长 0.394 秒，标准差 0.018 秒；每 10 秒窗口在 149.5–155.9 BPM 之间，全片没有明显变速。tempogram 的次选是 76 BPM（半速），本文按 152 BPM 的拍点和八分音符（0.197 秒）描述节奏。
- 音量（RMS）在 57–62 秒降到 0.045 左右，约为多数段落的三分之一，与黑底现代旁白段重合。

### 切换频率

- 颜色直方图变化不小于 0.5 的场景切换共 17 次，平均每 4.9 秒一次，中位间隔 2.38 秒。17 次全部落在八分音符网格 ±0.09 秒以内：10 次在拍点 ±0.06 秒，7 次在半拍。
- 节奏分布：开头 4.8 秒内切换 4 次（间隔 0.43、1.23、1.57、1.6 秒），先把节奏立起来；中段每段 1.8–4.8 秒；高潮 24.0–26.0 秒每拍切一次（4 个 0.4 秒）；后半段改用 7.5–17.9 秒的长段落。
- 长段落内部的事件密度很高，每 0.1–0.4 秒有一个文字或物件变化，按音符卡点：
  - 旁白逐字出现，每字 0.1 秒，等于十六分音符（56.0–58.4 秒）。
  - 诗句逐字出现，每字 0.2 秒，等于八分音符（18.0–19.2 秒）。
  - 方块字每 0.1–0.2 秒落下一个（6.7–8.0 秒）。
  - 地名每拍一个，同时月亮每拍放大一级（43.27、43.67、44.07、44.5 秒）。
- 另有 16 个候选突变属于同一场景内的大字替换、打光变化或闪帧。
- 单帧闪：4.933 秒暗闪，17.433 秒和 19.033 秒白闪，19.233 秒青色“怕”1 帧。闪帧放在重音画面之前。

### 运镜

| 运镜 | 做法 | 例 |
| --- | --- | --- |
| 拉远揭示 | 从一个字或一行字拉远，原画面变成新画面的一小部分 | 行书缩到角落（1.2→1.7 秒）；文字墙→书页网格→透视平原（5.2→6.7 秒） |
| 贴地前推 | 在透视平原上前推，物件随推进依次落下 | 文字平原上方块字逐个落下（6.7–8.2 秒） |
| 降低与侧倾 | 机位降低、画面侧倾，仰看被挑出的物件升起 | “盛”升起（8.5–9.2 秒） |
| 推近穿越 | 推向字形或物体，穿过去进入下一场景 | 穿过“〇”进入江面（26.0–26.7 秒）；推近山尖加径向模糊后清空（34.4–34.9 秒） |
| 低机位前移 | 贴着地面或水面前移，立体字从近处掠过 | 江面上的“大”（26.7–28 秒） |
| 固定机位加人物缓行 | 机位基本不动，人物横向慢走，纵深靠雾 | 竹林雨（14.5–24 秒） |
| 按拍放大 | 主体每拍放大一级，最后过曝 | 月亮（43.0–46.0 秒） |
| 完全固定 | 机位不动，运动全部交给文字和物件：逐字打出、倾倒坠落、发牌、翻牌、收拢 | 回顾、旁白、字卡段（50–55、55–65、65–83 秒） |

- 没有手持晃动，没有快速变焦；推、拉、移的速度平稳，加减速柔和。
- 镜头越接近结尾越静止，后 30 秒几乎只靠排版动画推进。

## 5. 转场方式

| 手法 | 做法 | 例 |
| --- | --- | --- |
| 粒子散聚 | 上一段的字或物散成墨点，墨点再聚成下一段的字或山 | 0.4–2.7、16–21、46.7–48、69.7–71、79–79.7 秒 |
| 关灯 | 构图不变，背景在拍点瞬间转暗，只留一个关键物保持颜色 | 9.63 秒、55.03 秒 |
| 过曝白场 | 把雾、月亮或高光推到全白，再从白进入纸面 | 9.2 秒、29.7–30.2 秒、45.5–46.7 秒 |
| 字形门洞 | 年份数字里填入下一场景的纹理，推进穿过“〇” | 24.8–26.7 秒 |
| 速度模糊 | 竖向条纹快速横扫进入新画面 | 3.2–3.7 秒 |
| 尺度连续 | 同一元素缩放到成为下一画面的一部分 | 1.2→1.7 秒、5.2→6.7 秒 |
| 元素承接与回收 | 关键物跨段保留，结尾回收成总结 | “盛”方块：6.7→12→54–55 秒；地名：43–44 秒→时间轴 51 秒→字卡 65.7 秒；作品名：24.8–26.2 秒→卡片背面诗句 66.7–67.7 秒 |
| 按拍换底色 | 前景字不动，背景每拍在黑、米白、橙之间切换 | 24.8–26.0 秒 |
| 单帧闪 | 1 帧白色或补色，下一帧是重音画面 | 19.033、19.233 秒 |
| 物理崩塌 | 文字断裂、倾倒、掉出画面，下一句从上方出现 | 57.7–58.5、61.2、62.7–63.2 秒 |
| 变灰淡出 | 文字先变灰，再淡到纸色 | 75.2–76.2、80.7 秒 |
| 清空后落物 | 清成空纸，底色渐暖，新物件从画外落入 | 34.9–35.3 秒 |

- 两个场景之间没有整屏叠化，也没有擦除、翻页之类的通用转场；每个转场都由画面里的元素（字、墨点、光、雾）完成。

## 6. 画面文字

### 字体（字形推断）

| 角色 | 字形特征 | 用途 | 可用的近似字体 |
| --- | --- | --- | --- |
| 大字标题 | 高反差粗宋，横细竖粗，笔画端带三角饰角 | 人名、年份、地名、关键词、结尾口号、黑底旁白 | Songti SC Black、思源宋体 Heavy |
| 旁白正文 | 常规宋体，字距明显放宽 | 纸面段现代旁白 | Songti SC Regular、思源宋体 Regular |
| 古诗句 | 楷体或仿宋，常做成墨点、点描质感 | 竖排诗句 | Kaiti SC、STFangsong |
| 书法 | 行书竖排 | 只在开场出现一次 | 书法图片或手写字体 |
| 数据 | 等宽字体 | 里程“0 km / 487 km / 1,299 km / 1,748 km”、生卒年 | Menlo、Courier |
| 计数器 | 粗无衬线 | 数字计数 1→38→225→300 | DIN Condensed |

### 颜色

- 暗底用暖白 `#FAF6F2`，纸底用墨黑 `#070300`。
- 每句最多一个强调词，用朱橙 `#FD602A` 或加粗加大：“三百颗”（36.7 秒）、“千古绝唱”（68.2 秒）、“苏轼把一手烂牌”里只加粗“苏轼”、“都会过去”整行加粗。
- 被否定或放下的词改成灰色并错位（“不用执着”，78.2 秒）。
- 发光只用于暗底：黑卡上的橙字带外发光，“浪淘尽”白字带柔光。
- 批注用红色手绘圈。

### 排版与出现时机

- 古诗竖排，放在左右三分线；现代旁白横排，放在画面上三分之一到中线。不使用底部字幕条。
- 字号差距极大（目测）：大字占画面高度 1/3 到满屏，旁白约 1/18，角标约 1/40。
- 逐字出现：旁白每字 0.1 秒（十六分音符），诗句每字 0.2 秒（八分音符），从拍点起打。
- 方块字每个 0.1–0.2 秒依次落下；地名每拍一个，满屏出现，下一拍缩进侧边列表。
- 句子打完后停 1–4 拍再变化；段落结尾的关键句停 2 秒以上。
- 文字和画面互动：被圈、被敲碎、倾倒坠落、散成墨点、堆成山形、化成飞鸿留下爪印（73.7 秒）。
- 右上角常驻角标，第一行小号宋体“地点 · 年份 · 事件”，第二行等宽里程；换章时更新（5.2 秒起“汴京 · 一〇五七 · 进士 / 0 km”，之后 487、1,299、1,748 km）；进入纸面回顾段后取消。
- 诗句下方加小号出处“篇名 · 年份”；年份数字下方每拍换一个作品名。

## 附录 B：新作品对照检查

新视频完成后执行，结果逐条修改：

1. 用 `分析视频.py` 测新视频，与本文件的 `测量.json` 比较 BPM、场景切换次数、切点到八分音符的最大偏差（参考值 0.087 秒）、单帧闪数量、饱和像素占比（参考值约 4%）。
2. 按附录 A 的段落功能，在新视频对应段落与参考视频同一段落各取开头、中点、结尾及每个切点前后各 1 帧，拼成并排对照图。
3. 逐段列出差距，至少检查：
   - 节奏：段落长度（秒和拍数）、段内事件间隔、逐字速度（0.1 秒或 0.2 秒每字）、切点是否在拍点或半拍。
   - 构图：主体所在三分线、人物占画面高度、大字与旁白的字号比、竖排或横排、强调色是否只落在一个字上、明暗交替顺序。
4. 每条差距写明位置（时间）、参考值、实测值和修改方法；修改后重测，直到全部关闭或说明保留理由。
