# 《嘉宾》纸艺开场样图

[02-纸艺拼贴.png](02-纸艺拼贴.png)：1920×1080 PNG，由 Canvas 2D 代码绘制，未使用图像生成模型。

## 画面

依据 `song.md` 的主题“在旧爱的婚礼上承认亲密关系已结束”，以及开场情绪“分手后第几个冬季”和“拿着喜帖一步一步走近”。

| 元素 | 含义 |
| --- | --- |
| 背对画面的人，停在路中央 | 走到一半、不愿再靠近；身后有脚印，身前没有 |
| 人物和礼堂之间的一大片雪地 | 关系的距离，是全图最空的区域 |
| 亮着金色窗户的礼堂、彩旗和花门 | “他精心布置的场地”，全图的暖色都集中在这里 |
| 钟楼里的金色小钟 | 预告第二段主歌的“钟声响起” |
| 红金纸屑混入雪片 | 只在礼堂一侧出现，飘到人物这边就只剩雪 |
| 人物手中的红纸与前景的大喜帖 | 同一张喜帖的两种尺度，红色只给这条叙事线和喜庆布置 |
| 席卡上的“嘉宾” | 全图唯一的词；画面文字只有“囍”和“嘉宾”三个字 |

配色是灰蓝天空、米白雪地和牛皮纸棕，亮度均值 185.8（0–255）。

## 纸艺规则

- 底纹：牛皮纸底在四周露出；天空、远山和喜帖衬底用旧报纸。报纸只有假字条和半调网点，没有可读文字。
- 边缘：天空、山、雪地、路和雪堆用撕纸毛边；人物、礼堂、喜帖等用剪纸白边。
- 层次：每张纸都有投影，投影随高度加大；画面共 16 个图层。
- 动画：每秒更新 10 次；除牛皮纸底以外，各层每次在两个轴上独立随机抖动 1–2 像素。

样图是不抖动的静态状态。预览动画：打开 `index.html?play`。

## 重现

```bash
node 嘉宾/开场样图/render.mjs
```

```bash
node --test 嘉宾/开场样图/scene.test.mjs
```

渲染需要本机 Chrome 和系统字体 Songti SC。脚本读取画布像素做数值检查，结果写入 [验证结果.json](验证结果.json)。未通过时不写 PNG。
