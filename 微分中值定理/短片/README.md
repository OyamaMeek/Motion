# 《从费马到柯西》短片工程

讲解从费马引理到柯西中值定理的逻辑链。成片 `输出/从费马到柯西.mp4`：1920×1080、30 fps、136 秒、4080 帧，H.264 视频、AAC 音频；画面和曲线全部由代码绘制，不用图片素材；配乐由仓库根目录的 `bgm.mp3` 和代码合成的一层混成。MP4、WAV 和 `bgm.mp3` 只留本地，不提交。

- 配色：米白 `#F2EDE4` 底、墨黑 `#161412`、亮橙 `#FF5B14`。标题字体 Songti SC Black（中文与公式），正文字体 Menlo（数值读数、坐标、场景编号）。
- `timeline.js`：120 BPM，每拍 15 帧，272 拍；开场总起 32 拍，之后 5 个场景 40/48/56/56/40 拍，切点在第 32、72、120、176、232 拍（都是小节首拍）；`KEYS` 是场景内的关键拍，`HIT_BEATS` 是配乐重音。
- `math.js`：费马的 `x³/3 − x`、罗尔的 7 个端点等高形状、拉格朗日的 `φ(u) + k·u`、柯西的参数曲线 `(g(t), f(t))`，以及极值点和 ξ 的数值求解；画面上的平切线、ξ 和切线方向都由这些函数实时算出。
- `script.js`：画面上的全部文字，每条不超过 14 字。
- `main.js`：Canvas 2D 绘制。
  - 开场总起：墨黑底上逐拍硬切。镜头每 2 拍换一个机位，搭出“一条曲线 / 两个端点 / 中间某一点 / 切线和弦平行”的整张图；四个定理名逐拍满屏砸下（米白、墨黑、米白、亮橙四种底色）；连成一条链；大标题“微分中值定理”加橙色平线；发问“为什么 / 曲线上总有这样一点？”；镜头冲进橙点，切进费马。
  - 场景一“费马”：大字切条拆开重组，公式、曲线图层和句子都按横条从两侧飞入飞出；笔头带坐标画出曲线，切点沿曲线走到最高点和最低点，右上角显示斜率。
  - 场景二“罗尔”：上一场景的“0”放大成圆环，压扁成两端等高的直线，再在钉住的两端之间连续变形 6 次，平切线标记对正在变形的曲线实时求出，留下前两个形状的细线。
  - 场景三“拉格朗日”：镜头穿过三块文字平面到达罗尔的图，图形加上倾斜 `k·x` 后弦与切线的斜率读数始终相同；公式五块放在不同深度，镜头横移到一个机位时拼成一行，最后镜头冲进 ξ。
  - 场景四“柯西”：粒子从橙色圆点炸开，聚成参数曲线，再依次聚成柯西公式、拉格朗日公式（令 g(x)=x，橙色的 g 部分流向 b − a）和标题。
  - 场景五：胶片条急停在四个定理上，箭头标出每一步加了什么；随后回到费马公式，收在“四个定理，一个根源 / 极值处，切线是平的”和一道橙色平线。
  - 文字安全区检查：处于阅读位置的文字墨迹超出左右 60、上下 40 像素即记为渲染错误，镜头穿越和切条飞行中的文字不算。
- 配乐：
  - `analyze-bgm.py`（`.agent/venv` 的 librosa）测量 `bgm.mp3`，写入 `bgm-analysis.json`：112.90 BPM、第一拍 0.539 秒、小节首拍相位、每 8 拍能量、每小节和弦（F 小调，Fm–Fm–D♭–E♭ 循环）。前 32 拍是前奏，第 144—176 拍是间奏。
  - `music.mjs`：bgm 用 ffmpeg `atempo` 变速不变调到 120 BPM，第一拍对齐成片第 0 拍；剪掉 bgm 第 192—224 拍一句（接缝前是 E♭、后是 F，15 ms 交叉淡化）。这样 bgm 前奏垫在开场总起下，正歌在费马切点进来，间奏落在拉格朗日的公式拼合，第二段在柯西切点进来，结尾段落在片尾回顾下。bgm 在开场压低，让大鼓和低音重击在前；每个切点前 150 ms 压低 bgm，让切点重击和 bgm 的鼓拉开。合成层：开场的大鼓和铜管式低音重击、各场景的风声与上扬、切点和锁定动作的重音、粒子碎点、放映机声；有音高的部分取 bgm 当前小节和弦的根音和五度，不叠 bgm 已有的鼓组和贝斯；结尾停在 F 小调主和弦。
  - `export-bgm-stem.mjs` 导出剪辑后的 bgm 单轨，`check-bgm-grid.py` 检查它的拍点相对成片拍格的偏差和小节首拍位置。
- `render.mjs`：复用 `會呼吸的痛/開場樣圖/v2/chrome.mjs` 驱动多个无头 Chrome 分段渲染，ffmpeg 编码并混入 AAC；任何一帧 60 秒未返回即终止。约 6—10 分钟，期间电脑不能睡眠。
- `verify-export.mjs`：规格、音画起点、切点卡拍、空白帧（按每帧自己的底色）、重音偏差、响度、真峰值、削顶、爆音、中断，结果写 `输出/导出检查.json`，波形图写 `输出/波形.png`。
- `extract-frames.mjs`：每个场景每 2 拍抽一帧，每个切点抽前 3 帧到后 2 帧。
